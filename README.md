
# TaskMaster - Full-Stack Real-Time Task Management Application 🚀

A professional, real-time task management system built with full-stack architecture, WebSocket support, and modern UI.

![Status](https://img.shields.io/badge/Status-Live-success)
![FullStack](https://img.shields.io/badge/FullStack-MERN-blue)
![RealTime](https://img.shields.io/badge/RealTime-WebSocket-purple)

## ✨ Live Demo
Local URL: `http://localhost:5000`
GitHub: `https://github.com/mukkaralakshmideekshitha-885/task-management-application`

## 🌟 Features

- **Real-Time Updates** - WebSocket active on `ws://localhost:5000`
- **Drag & Drop** - To Do, In Progress, In Review, Completed
- **Task Analytics** - Total Tasks, Completion Progress (40% bar)
- **Smart Search** - Search by title, tag, description
- **Filters** - By Stage, Priority, Category
- **Persistent Storage** - JSON Persistent Store (no data loss)
- **Professional UI** - Dark theme, responsive design

## 🛠️ Tech Stack

**Frontend:** HTML5, CSS3, JavaScript, Drag & Drop API
**Backend:** Node.js, Express.js
**Real-Time:** WebSocket (ws)
**Database:** JSON Persistent Store
**Other:** REST API - `/api/health` for health check

## 🚀 How to Run Locally

### 1. Clone the repo
```bash
git clone https://github.com/mukkaralakshmideekshitha-885/task-management-application.git
cd task-management-application
### 2. Start Backend Server
cd server
npm install
npm start
Server will start at: `http://localhost:5000`

### 3. Start Frontend (if separate client folder)
cd client
npm install
npm start
### 4. Open in Browser
http://localhost:5000

DELETE | `/api/tasks/:id` | Delete task
